    How this works

    The page talks to api.github.com directly using your PAT. The repository is created via POST /user/repos or POST /orgs/{org}/repos, then a repository ruleset is created on the default branch with pull_request, non_fast_forward, and deletion rules as configured.

    "Admin bypass" adds the repository Admin role (id 5) to the ruleset's bypass_actors, so anyone with admin (you, as the owner) can push or merge without going through the ruleset.

    Your token is kept in memory by default. The "Remember" checkbox stores it in this browser's localStorage — convenient, but anything running on this origin could read it.
